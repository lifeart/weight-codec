The page downloads our compressed .wcdc files, entropy-decodes them (rANS, plain JavaScript), rebuilds the fp16 weights, checks their SHA-256 against the Python decoder, and then generates text with the rebuilt weights. No server, no GPU, no official weight file is downloaded.

    4 · Generate text with the rebuilt weights

    Live generation runs on the weights rebuilt in step 2 — the same buffers whose SHA-256 was just checked — through this page's own small JavaScript Llama forward pass (fp32 math, one CPU thread in a Web Worker, greedy decoding). It is not transformers.js / ONNX and not the official weights. Offline test (phase2/test_demo.mjs): this forward pass reproduces PyTorch's greedy tokens on the same rebuilt weights for every test prompt (logits within 4·10⁻⁵).
